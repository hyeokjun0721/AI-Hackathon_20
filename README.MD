# 핏노트 로컬 웹 화면

설치할 패키지 없이 Python으로 실행합니다.

```powershell
python size_webapp.py
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 터미널은 실행 상태로 둡니다.
종료하려면 터미널에서 Ctrl+C를 누릅니다. 포트가 사용 중이면 `--port 8001`을 추가합니다.

## 필요한 파일

```text
size_recommender_gemini.py      상품 수집·추천 코드
size_webapp.py                  로컬 웹 서버
web/
  index.html                   내 옷 3개 등록 화면
  compare.html                 새 옷 비교 화면
  onboarding.js                등록·저장 흐름
  style.css                    디자인
  app.js                       화면 동작
```

테스트 파일은 웹사이트 실행에 필요하지 않습니다.

## 사용 방법

1. 첫 화면에서 잘 맞았던 옷 3개의 무신사 상품 URL과 구매 사이즈를 입력하고 저장합니다.
2. 다음 화면에서 새 상품의 무신사 URL과 원하는 핏을 입력합니다.
3. 키 없이 실측 비교만 하거나, Gemini API 키를 입력하고 추천을 받습니다.

저장된 기준 옷과 새 상품의 실제 사이즈표로 부위별 치수 차이를 표시합니다. 새 상품의 재질과 최신 후기 1개도 보여 줍니다.
Gemini 요청 실패 시에도 비교표는 유지되며, 키를 다시 입력하고 AI 추천만 재시도할 수 있습니다.
비교 결과는 서버 메모리에 최대 15분 동안 유지합니다. 파일에는 저장하지 않습니다.
API 키는 요청 처리에만 사용하며 서버 파일·로그·브라우저 저장소에 저장하지 않습니다.
웹 화면은 기존 Python 파일에 하드코딩된 키를 사용하지 않습니다.

현재 무신사 상품과 어깨·총장·가슴단면이 제공된 상의를 지원합니다.
다른 의류 유형이나 실측표가 없는 상품은 비교되지 않을 수 있습니다.
실제 착용감, 재고, 구매 가능 여부를 보장하지 않습니다.

로컬 PC에서 사용하는 개발용 서버이며 인터넷에 공개 배포한 사이트는 아닙니다.
127.0.0.1에만 바인딩합니다. 공개 배포에는 별도 서버 구성과 접근 관리가 필요합니다.
# 내 옷 3개 등록 흐름

첫 화면(`/`)에서 서로 다른 무신사 상의 3개의 URL과 실제 입었던 사이즈를 입력합니다.
세 옷의 실측을 모두 검증한 뒤 이 컴퓨터의 `data/fit_profile.json`에 프로필 하나를 저장하고
다음 화면(`/compare`)으로 이동합니다. 서버를 껐다 켜도 저장한 옷을 재사용합니다.
다음 방문에는 저장한 옷으로 계속하기 또는 수정하기를 선택할 수 있습니다.
수정 도중 수집에 실패하면 이전 프로필은 유지됩니다. API 키는 저장하지 않습니다.

프로필에는 세 옷의 상품 정보·선택 사이즈·실측과 부위별 최소/최대/평균이 들어갑니다.
이는 잘 맞는 옷의 치수 범위이며 사용자 신체 치수나 체형에 대한 추정은 아닙니다.
다음 화면에서는 새 상품 정보만 표시합니다. 비교 기준은 기존 기본값인 첫 번째 저장한 옷을 내부적으로 사용하며, 저장한 세 옷의 정보는 첫 화면에서 확인·수정합니다.
현재는 이 로컬 앱을 쓰는 한 사람의 프로필만 지원하며 계정별 분리는 없습니다.
